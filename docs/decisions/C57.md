# C57: Task 19 may correct only the Product-lens path and table-code selectors in `assets/reader.css`

*Recorded 2026-10-21, coordinator.* · [Decision log](README.md)

## Decision

The two rules still require a descendant `main.container`, although the enhanced element itself owns the reader and its lens class. Remove only that obsolete descendant requirement, retaining the root scope, screen media query and declarations. The specificity decreases only by the removed `main.container`; add no compensating selector. A dedicated `test/browser/settings-path.test.ts` owns the regression, leaving the ongoing settings tests and mutation journal to their current writer.
- Measure the original rule red and the source replacement green in Chromium and offline WebKit, at 1440 px and 390 px in light and dark. Verify path and table-code computed styles, unchanged Product-off styles, and isolation between independently enhanced sibling roots. Use the actual stylesheet, not an appended override.
- Preserve the warm palette, all other selectors, existing goldens and hostile verdicts. This grants no general stylesheet rewrite, shared-test extension, performance decision, or task acceptance. Record the exact selector reversal and its assertion failure outside the concurrently owned Task 19 journal for later reconciliation.

## Why

Independent file-only comparisons established that the reference quiets paths but an ordinary enhanced root cannot match the ported selector; the scratch override alone did not verify a source replacement.

## Cost if wrong

A selector correction could affect unrelated code or a sibling reader, so both negative controls are required.
