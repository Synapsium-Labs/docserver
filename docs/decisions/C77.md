*Recorded 2026-10-25, coordinator.* · [Decision log](README.md)

## Decision

The direct-child prose rule caps the fullscreen overlay at the reading measure; reset only the overlay's maximum width and margins. Its detached SVG clone must use the natural viewBox viewport that the existing fit calculation consumes: set numeric width/height attributes and the already permitted width style, without changing the source, nested paint, ID rebinding or the closed style-property list. Separate browser regressions measure the capped overlay and mismatched clone viewport before the correction. Authentic host base CSS also proves that the reference rail and drawer widths already include padding under border-box; remove the two extra padding compensations and correct implementation-pinned bounds to the reference's independently measured outer/inner widths, preserving the source-column gutter. LD10 permits placement differences, not wider inner components. The Keys sheet remains binding-dependent as Task 16 requires; compare equal applicable rows or name only a proven row-dependent difference, never change key behavior merely to equalize height.
