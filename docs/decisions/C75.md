# C75: Retain the breached evidence and raise the cumulative acceptance-artifact ceiling from 5 MiB to 6 MiB

*Recorded 2026-10-25, operator.* · [Decision log](README.md)

## Decision

A delegated test emitted a large assertion diff and crossed the original cumulative cap. Existing receipts remain immutable; none is deleted, shortened or rewritten to repair that breach. The operator approved the new ceiling with output limits enforced by the runner. Each new command therefore starts behind a bounded-output wrapper: if output reaches its limit or execution times out, only that recorded process group is stopped and the receipt is labelled incomplete, never passing. This changes the evidence allowance and execution containment, not any test, geometry tolerance, required result or release gate.
