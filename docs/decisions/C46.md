# C46: PD8 covers PyYAML's simple-key limit

*Recorded 2026-10-20, coordinator, from L2 Task 1's review.* · [Decision log](README.md)

## Decision

PyYAML refuses a simple key whose source text is longer than 1024 characters, so the reference renders nothing for that block, while `render()` loads it and cuts the key to 500 code points ([C31](C31.md)). Only a hostile or machine-made document writes such a key, so it joins PD8's bounds. This corrects [C31](C31.md)'s "cost if wrong", which said the reference renders an over-cap key whole: that holds only up to 1024 source characters. No code change; Task 1's boundary case pins the behaviour, and the README's PD8 row gains the line in Task 24.

## Cost if wrong

Such a block renders where the reference renders nothing.
