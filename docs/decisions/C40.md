# C40: Prototype first

*Recorded 2026-10-19, operator.* · [Decision log](README.md)

## Decision

The paper L2 plan loop is retired. L2's plan is written from running code, and each remaining task is built the same way: code, tests, mutation rows and a visual comparison, not code blocks specified in prose.

## Why

The paper plan stopped converging, while the prototype proved the hard parts (the lifecycle, the journal and the stylesheet's scoping) in running code.

## Cost if wrong

Less of each task's code is reviewed before it is written. The held-out panel on every task and the whole-branch review carry that weight.
