# C23: PD6 covers reference-label normalisation

*Ruled with the L1 plan, 2026-10-12.* · [Decision log](README.md)

## Decision

A few rare whitespace characters (`\x1c`-`\x1f`, U+0085 and U+FEFF) behave differently in reference labels. Each is pinned by a unit case. Three more parser rules are not ported for this. Cost if wrong: those rules are ported later and the cases move.
