# C1: PD1-PD4 accepted

*Ruled with the L1 plan, 2026-10-12.* · [Decision log](README.md)

## Decision

PD1: code highlighting is normalised when comparing. PD2: front-matter scalars follow YAML 1.2 core, so `null` renders as empty and booleans render as `true` or `false`. PD3: the front-matter list comes from the same block that is stripped. PD4: a leading BOM is stripped.

## Why

A public library should not print Python's `None` or `True`, and one parser keeps the strip and `meta` consistent.
