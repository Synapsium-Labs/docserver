# C8: The engine's rule chain

*Ruled with the L1 plan, 2026-10-12.* · [Decision log](README.md)

## Decision

The core chain is `normalize, block, block_strip, inline, text_join, anchors, line_attrs`, plus the plugin rules later tasks add, each named where it is added. `block_strip` gives heading and paragraph text Python's `str.strip` semantics.
