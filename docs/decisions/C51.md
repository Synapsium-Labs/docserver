# C51: WebKit runs on the build box after all, in the Playwright image; C45 is narrowed

*Recorded 2026-10-20, coordinator.* · [Decision log](README.md)

## Decision

The browser tests run in WebKit in the official Playwright image of the pinned version, `mcr.microsoft.com/playwright:v1.63.0-noble`: `docker run --rm --network none`, as the box's own user, on a copy of the tree. No root is needed and no system package is installed. So a task runs its browser cases in both browsers before it hands off; CI stays the arbiter. Task 7b's first WebKit run in CI failed one case, and the image reproduced it at once. WebKit fires the font set's `loading` event for the faces of a stylesheet added after `enhance()`, but never `loadingdone`, so the fonts wait now asks again at `loading` too.

## Cost if wrong

A 2 GB image on the box, and a WebKit difference that the image's build does not share with CI's.
