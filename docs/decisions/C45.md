# C45: The build box runs the browser tests in Chromium only, by explicit selection; CI runs Chromium and WebKit

*Recorded 2026-10-20, coordinator.* · [Decision log](README.md)

> [!NOTE]
> Amended by [C51](C51.md); read them with this one.

## Decision

The box has no WebKit system libraries, and installing them needs root, which no worker uses. Task 6's harness takes the selection as an environment setting; with no selection a missing browser is red and names the install command, and an excluded browser is reported as excluded, never skipped silently.

## Cost if wrong

A WebKit-only break is first seen in CI.
