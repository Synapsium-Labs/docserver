# C111: A push went out before its public-text check was read, fixed forward

*Recorded 2026-11-05, coordinator.* · [Decision log](README.md)

## Decision

(1) During the wave one push ran although the repository's pre-push public-text check had reported a hit: the push gate read a pipe's exit status, not the check's. (2) The text was fixed forward in a later commit on the same branch, and the check reports no hit on the tip. (3) The coordinator ruled no history rewrite ([C105](C105.md) (4)). (4) Since then every push is gated on the check's own exit status.

## Why

A slip that cannot be unpushed is recorded with its cause, so the gate that failed is the one that is fixed.

## Cost if wrong

One stray token in a public commit's history; it names no host, person, product or path.
