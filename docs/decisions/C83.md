# C83: The library's repository stays private

*Recorded 2026-10-26, operator, withdrawn by C84.* · [Decision log](README.md)

> [!CAUTION]
> Withdrawn by [C84](C84.md).

## Decision

The operator ruled that `docserver` will not be a public repository while it is a separate repository. This overturns "private until v1, public from v1" (the first consumer's spec, ruling R-g) and removes the repository flip and its pre-flip history and GitHub-text scan from L3. Measured consequences: npm generates no provenance for a package published from a private repository (a trusted publish skips it; an explicit `--provenance` is refused), and GitHub build attestations for a private repository need GitHub Enterprise Cloud, which this organisation's Team plan is not. So the first consumer's provenance identity check (its §3.6 CI row and M8.16) cannot be met as written. How consumers obtain and verify the library is the operator's next decision; until it is made, L3's release tasks (14 and 15) and the first consumer's spec amendments wait, and Tasks 1 to 13, 16 and 17 are unaffected. The rule that shipped files carry no private names stays: whatever the distribution, the built files reach the first consumer's public releases.

## Why

The operator's ruling.

## Cost if wrong

None to the code; the release lane is rewritten once the distribution is chosen.
