# C93: Task 13 (Mermaid 12.2.0) is deferred past v1

*Recorded 2026-10-27, coordinator.* · [Decision log](README.md)

## Decision

The move needs Mermaid 12.2.0 installed in the working tree, because the frame manifests carry the Mermaid file's hash and length and only a build from the installed package can regenerate them; the programme's standing rule forbids dependency installs here, and the plan gives no reason for the move beyond doing it before v1 and before the browser rows set their baselines. v1 ships the pinned Mermaid 12.1.0, whose module and frame builds, parity rows and both-engine drawings are already proven; the upgrade becomes a later minor release with its own re-baseline of the Level 2 cases and the Mermaid rows. The edges T13 to T8 and T13 to T14 drop: Task 8 baselines on 12.1.0, and Task 14's notices carry 12.1.0's version strings.

## Why

An install the operator's rule forbids would otherwise block the release for a version bump the release does not need.

## Cost if wrong

v1 carries the older Mermaid, and a host that needs 12.2.0 waits for the next minor; the operator can overturn this and allow the install.
