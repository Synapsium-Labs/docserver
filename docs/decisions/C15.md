# C15 to C17: PD2 restated

*Ruled with the L1 plan, 2026-10-12.* · [Decision log](README.md)

## Decision

Front-matter scalars render their source text: `version: 1.0` shows `1.0`, and a 20-digit integer keeps every digit. `null` renders as empty and booleans as `true` or `false`. The YAML schema is FAILSAFE plus null, bool and merge (C15: the merge key is accepted). PD2 also covers eight named loader differences, each pinned by a unit case.

## Why

A display library shows what the author wrote.

## Cost if wrong
