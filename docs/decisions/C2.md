# C2: Shape

*Ruled with the L1 plan, 2026-10-12.* · [Decision log](README.md)

## Decision

`render()` returns `{html, outcome, bytes, meta}`, with no overloaded empty value. `meta` holds the front matter, its list, the title, headings, figures, tables and Mermaid kinds. `scanRefs()` gains `outcome` and `imagesTruncated`. This refines a comment in ccrc's spec §3.2, and ccrc's ledger records that.
