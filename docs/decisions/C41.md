# C41: The reference's warm colour palette is kept exactly, in light and dark

*Recorded 2026-10-19, operator.* · [Decision log](README.md)

## Decision

Earlier drafts of the L2 plan, never merged, left the palette out; this ruling keeps it.

## Why

Readers keep the look they know, and visual parity can be measured.

## Cost if wrong

The library ships one opinionated palette. A host overrides the tokens on the root.
