# C74: Snapshot review records every approved change, while trailers name only actual ratchet moves

*Recorded 2026-10-25, coordinator.* · [Decision log](README.md)

## Decision

Scoped review accepts the seven [C68](C68.md) deltas without unrelated changes. The ratchet excludes newly added snapshots from its movement set and rejects an extra `Layout-moved:` name. Keep all seven cases in the review record and release notes, but derive commit trailers from the actual moved-case set against the eventual integration base and commit range after synchronization. A case absent from that base is added, not moved; [C68](C68.md)'s unconditional seven-name trailer instruction is superseded only for that distinction. No golden, hostile verdict, input or expected-content rule changes.

## Why

A false extra trailer is itself a red ratchet.

## Cost if wrong

A movement could be omitted; remeasurement against the final base, rather than a prepared name list, is mandatory.
