# C20: An output bound

*Ruled with the L1 plan, 2026-10-12.* · [Decision log](README.md)

## Decision

A new option, `maxHtmlBytes`, defaults to 16 MiB, four times `maxBytes`. When the HTML would exceed it, `render()` stops and returns outcome `output-over-limit`. That outcome is never folded into `rendered` or into the input-size outcome. The HTML is then the escaped-source fallback, truncated to stay within the bound.

## Why

One 304 KB input produced 200 MB of HTML.

## Cost if wrong

A host sees a fallback where it expected a page; it can raise the bound.
