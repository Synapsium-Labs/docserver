# Parity Task 9 (layout infrastructure): mutation rows

Each row was measured in place on this wave's branch: the bytes of the file saved with their sha256, one edit applied (and, for the two rows whose edit is in a build input, `npm run build:frame` run), the one named test file run through the fleet test wrapper, then the file restored from the saved bytes and its sha256 compared (and `npm run build:frame` run again for those two rows, after which `assets/assets.json` and `src/frame/manifest.generated.ts` were byte-equal to their committed text). Two rows were not red at first.
