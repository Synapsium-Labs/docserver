Each row was measured in place, one at a time: the file's bytes (and, for the frame's bundle, the generated manifest) were saved and their sha256 taken, the edit applied once, the focused test file run through the fleet test wrapper (`ccrc test -- ./node_modules/.bin/vitest run --maxWorkers=2 <file>`, the browser file with `DOCREADER_BROWSERS=chromium`), and every file rewritten from the saved bytes with its sha256 checked equal (every row below restored byte for byte). The control (no edit) is green: `test/enhance-inshort.test.ts` 36 passed, `test/browser/frame-inshort.test.ts` 14 passed (Chromium; the 14 WebKit rows run only on CI). Notes.
