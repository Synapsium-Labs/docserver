# Readiness Task 3: RF3's timing oracle, with the root's live children list taken out of what a toggle times

RF3 (`test/enhance-plans-rf3.test.ts`) failed on CI's Node 24 leg only: 8 of 197 completed Node 24 jobs since it landed (4.1 %), 0 of 198 on Node 22, always on the toggle ratio (`b.toggle <= 2.5 * a.toggle`), received ratios 2.60 to 3.26 with `a.toggle` low (0.38 to 0.47 ms) and `b.toggle` ordinary. The cause, measured: about 98 % of an outline toggle's time in jsdom is jsdom rebuilding the root's live `children` list, which it does eagerly on every attribute change of the root once anything has read it (the features read `Array.from(root.children)`). That walk is linear in the root's children (1,709 and 3,385) but memory-bound, and its cost per child depends on where that copy of the plan sits in memory (up to 1.8 times between two copies of the same plan). The test mounts one copy of each size per process, so each job draws one pair of layouts, and on Node 24 a lucky 1x copy pushes the ratio over 2.5. No protocol or estimator change removes it (warm-up, alternation, longer batches, medians leave the model's ratio where it was). The change: `mount` gives the test's root an own `children` getter that returns a plain array, so jsdom never makes the live list, and a toggle times the outline's own work. No threshold, budget, run count or batch count moved; no `src/` change.

Each row was measured in place, one at a time: `src/enhance/plans.ts` was saved and its sha256 taken (47de9edb6a993166...), the plant applied once, the changed test file run through the fleet test wrapper (`ccrc test -- ./node_modules/.bin/vitest run --maxWorkers=2 test/enhance-plans-rf3.test.ts`), and the file rewritten from the saved bytes with its sha256 checked equal. No row used `git checkout`, `git stash` or `reset --hard`. The ratio and budget assertions are the guards; the children shim is a measurement fix, not a guard. The numbers a green run does not print, and the four numbers of a red run, come from a scratch copy of the same file with one line added that prints the numbers before the assertions (imports made absolute, outside the tree), run through the same wrapper; both the real file and the copy are listed. Control, no plant, shim in: green, toggle ratios 0.98 to 1.07 on Node 24 (four runs) and 0.88 on Node 22.
