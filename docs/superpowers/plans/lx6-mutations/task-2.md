# LX6.2: screen pages, mutations

Each row was measured in place, one at a time: the file's bytes were saved and their sha256 taken, the edit applied once, the frame rebuilt (`npm run build`, because the browser cases mount the frame's release bytes and verify them against the committed manifest), the focused cases of `test/browser/frame-pages.test.ts` run through the box's test wrapper under Chromium (`DOCREADER_BROWSERS=chromium ./node_modules/.bin/vitest run test/browser/frame-pages.test.ts -t <the row's cases>`), and the file rewritten from the saved bytes with its sha256 checked equal to the saved one (nothing was restored with git). After the last row the frame was built again from the restored bytes.

The control (no edit) is green: `test/browser/frame-pages.test.ts` 37 passed under Chromium (the other 36 are the WebKit blocks, skipped on this box: WebKit cannot launch here, so no case of this task has run under WebKit). A row's "first" is the first failing case of the run, by its title; "N failed" counts the cases of the row's pattern that failed.

Rows are numbered P (src/enhance/pages.ts), E (src/enhance/env.ts) and C (assets/reader.css). Guards and code found redundant by a first green measurement were deleted rather than kept: the `b.width < 1` test of what is pinned, the character before and after the caret, the estimate from one character that stood in for the line tiling, a turn guard on the scroll height (a turn that moves nothing now changes nothing, row P57), a reset of what is pinned on every relayout and a MutationObserver (the element count now decides), stopping the scroll listener when the mode goes off, `fonts` as a relayout reason, and a `frozen` flag with its resize listener (the root's width observer already runs the relayout before a late scroll is noted). Cases were sharpened where a row first measured green: the sliver at the top (the first whole line is checked at 0.01 px), the row that a back turn puts just below the bottom edge, a double click, a drag and a long press in the empty margin (a press on text selects it, which hid the thresholds), a short view where the band is 48 px and not 15%, a resize with the page's own scroll anchoring off, and a hand scroll before a width change.
