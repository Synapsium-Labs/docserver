# Hostile names

**Spec** · 2026-10-20 · Status: Draft

## Glossary

| Term | Meaning |
|---|---|
| \_\_proto\_\_ | A name a plain object would read as its prototype |
| constructor | A name every object answers |
| toString | Another one |
| C++ (cpp) | A name with pattern characters, and its alias, a term of its own |
| a.b*c | Dots and a star, matched as written |
| R12 | An ID, never a term |
| AB-CD | A rule ID, never a term |

## 1. Mentions

The \_\_proto\_\_ link, the constructor link and the toString link are ordinary terms.

C++ links, and so does cpp, its alias. The a.b*c name links, and aXbbc does not.

R12 and AB-CD stay text.
