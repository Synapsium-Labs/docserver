# Plurals

**Spec** · 2026-10-20 · Status: Draft

## Glossary

| Term | Meaning |
|---|---|
| Box | A container |
| Read mark | A mark on a section |
| Read | To take in |
| Lamp, Wick | Two names, each matched as spelled |

## 1. Endings

Two BOXES: a plural in es links, in any case.

The READ   MARKS: a plural in s links, and a run of spaces inside a name matches its one space.

In lower case, lamps do not link: an exact name matches only as spelled. Lamps as spelled do.

## 2. Word edges

An unboxed thing, a box-shaped one and a box_like one do not link: a letter, a dash or an underscore touches the word.

A box links. A second box does not: a term is linked once in a section.

## 3. Longest first

A read mark links as one name, the longest that starts there. In the read marker a letter follows the longer name, so the shorter one links.
